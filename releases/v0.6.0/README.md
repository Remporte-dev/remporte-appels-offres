# Remporte 0.6.0

Téléchargez l’archive de votre plateforme et consultez [INSTALLATION.md](INSTALLATION.md). Les paquets Muse et ChatGPT Work incluent le CLI.

Le CLI est disponible sur PyPI (`uv tool install remporte==0.6.0`). Il peut aussi être installé depuis le fichier fourni ici :

```bash
uv tool install https://raw.githubusercontent.com/Remporte-dev/remporte-appels-offres/main/releases/v0.6.0/remporte-0.6.0-py3-none-any.whl
```

Les empreintes des fichiers distribués sont dans SHA256SUMS. Le code validé porte le tag v0.6.0. La [release GitHub](https://github.com/Remporte-dev/remporte-appels-offres/releases/tag/v0.6.0) fournit aussi les archives par plateforme et le guide d’installation.
