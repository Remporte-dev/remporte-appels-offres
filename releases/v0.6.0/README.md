# Remporte 0.6.0

Téléchargez l’archive de votre plateforme et consultez [INSTALLATION.md](INSTALLATION.md). Les paquets Muse et ChatGPT Work incluent le CLI.

Pour installer cette version du CLI avant sa disponibilité sur PyPI :

```bash
uv tool install https://raw.githubusercontent.com/Remporte-dev/remporte-appels-offres/main/releases/v0.6.0/remporte-0.6.0-py3-none-any.whl
```

Les empreintes des fichiers distribués sont dans SHA256SUMS. Le code validé porte le tag v0.6.0. Ces téléchargements directs servent de relais tant que le service de releases GitHub refuse la publication.
