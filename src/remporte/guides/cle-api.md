# Clé API Remporte

Sans clé, le CLI fonctionne entièrement là où vous le lancez, sans aucun appel
réseau.

Une clé API Remporte donne à votre agent accès aux données que votre
entreprise a déposées dans l'application Remporte :

- la base de connaissances : recherche et lecture des documents ;
- la fiche entreprise ;
- la charte : mise en page et format des documents de l'entreprise.

Créer votre clé API : https://remporte.fr/outils/agent-ia/#cle-api

Données transmises avec une clé :
https://github.com/Remporte-dev/remporte-appels-offres/blob/main/PRIVACY.md
