# Planning, organigramme, schémas

> Puissance de modèle conseillée : standard (`remporte guide modeles`).

Un planning, un organigramme ou un schéma de méthode se lit plus vite qu'un
paragraphe. Ils servent un critère noté : ne les produis que si une section du
plan les appelle, ou si le RC les demande en annexe.

1. **Demande le modèle** à l'utilisateur : présentation de l'entreprise, ancien
   planning ou organigramme, charte graphique. Pars de ce fichier s'il existe.
2. **Écris d'abord le contenu** dans la section concernée de `sections/` :
   - planning : phases, jalons, durées, dates, en cohérence avec les délais du
     CCTP et du CCAP ;
   - organigramme : noms, rôles, rattachements, tirés de `remporte base
     chercher` (CV, moyens humains) ;
   - schéma de méthode : étapes, acteurs, livrables, contrôles.
   Rien d'inventé : `[à compléter : …]` pour ce qui manque.
3. **Produis le visuel avec tes propres outils**, dans le format qui convient :
   présentation PowerPoint pour un planning ou un organigramme riche, image à
   insérer dans le mémoire, ou tableur pour un planning détaillé. Range-le dans
   `annexes/` et cite-le dans la section qui s'y appuie.
4. Vérifie que le visuel dit la même chose que le texte : mêmes dates, mêmes
   noms, mêmes effectifs.
